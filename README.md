# MeshKids Chat (Android App fuer MeshCore)

Kinderfreundliche Android-Chat-App fuer MeshCore-LoRa-Funkgeraete mit Eltern-PIN-Bereich, Alias-Namen, Kanal-/PSK-Verwaltung und 3-Minuten-Zustellbestaetigung.

Wichtiger Hinweis:
Hier wird laufend gearbeitet, die Comunity hilft mit.
Das bedeutet aber, das die Dateien in sehr schnellen Rythmus geändert werden können.
Deswegen bitte Hinweise immer auf das aktuelle Release beziehen, und nicht auf die hier sichtbaren Dateien.
Requests sind deswegen nicht immer einpflegbar, da es vielleicht schon wieder Änderungen gibt.
Issues werden auf jeden Fall beantwortet.
